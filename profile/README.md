# AgentEarth

**One gateway, <!--TOOL_COUNT_FORMATTED-->2,700+<!--/TOOL_COUNT_FORMATTED--> tools for AI agents.**

AgentEarth lets AI agents call image & video generation, web search, data and productivity tools through a single entry point — an MCP endpoint, a CLI, or a skill — with one account and pay-per-use billing.

[Website](https://agentearth.ai) · [Contact](mailto:contact@agentearth.ai)

## What you'll find here

This organization hosts the open-source parts of the AgentEarth ecosystem. Repositories are being published step by step:

- **Connectors & plugins** — ready-to-use integrations for agent clients
- **CLI & SDKs** — call AgentEarth tools from scripts and your own apps
- **Community skills** — skills built on AgentEarth by the community
