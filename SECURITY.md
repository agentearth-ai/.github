# Security Policy

We take the security of AgentEarth and its users seriously. Thank you for helping us keep it safe.

## Reporting a vulnerability

**Please do not report security issues through public issues, discussions, or pull requests.**

Report privately through one of these channels:

1. **GitHub private vulnerability reporting** — on the affected repository, go to the **Security** tab and click **Report a vulnerability** (if enabled).
2. **Email** — send details to **contact@agentearth.ai** with the subject line starting with `[SECURITY]`.

Please include, where possible:

- The affected repository, component, or URL
- Steps to reproduce, or a proof of concept
- The impact you believe it has
- How we can contact you for follow-up

## What to expect

- We aim to acknowledge your report within **3 business days**.
- We'll keep you updated as we investigate and fix the issue.
- Please give us reasonable time to fix the issue before disclosing it publicly. We're happy to credit you once it's resolved, if you'd like.

## Scope

- Code in repositories under the `agentearth-ai` organization
- AgentEarth services at `agentearth.ai`

## Leaked credentials

If you find an AgentEarth API key or other credential exposed in public (code, logs, screenshots), please report it the same way so we can revoke it. Please don't use it.
