# agentearth-ai/.github

Organization-wide defaults for [agentearth-ai](https://github.com/agentearth-ai):

- `profile/README.md` — the organization profile page
- `CONTRIBUTING.md`, `SECURITY.md`, `CODE_OF_CONDUCT.md`, `SUPPORT.md` — default community health files used by every repository that doesn't provide its own
- `.github/ISSUE_TEMPLATE/`, `.github/pull_request_template.md` — default issue and pull request templates
- `.github/workflows/update-tool-count.yml` — keeps the tool count on the profile page in sync with [agentearth.ai](https://agentearth.ai) (daily, from `/api/client/tools/statistics`)
