# Getting Help

- **Bugs and feature requests** for open-source code: open an issue in the relevant repository.
- **Account, billing, or product questions** about AgentEarth: visit [agentearth.ai](https://agentearth.ai) or email **contact@agentearth.ai**.
- **Security issues**: please follow our [security policy](SECURITY.md) and report privately.

When asking for help, never share your API key or other secrets.

---

**中文：** 开源代码的问题请在对应仓库提 Issue；账号、计费、产品问题请访问 agentearth.ai 或发邮件至 contact@agentearth.ai。请勿在任何地方公开你的 API Key。
